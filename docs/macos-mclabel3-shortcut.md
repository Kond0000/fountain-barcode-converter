# mC-Label3 Print - macOS初回セットアップ

LABEL PRINTの「mC-Label3で印刷」は、ページ別の1ページPDFと実寸情報をZIPへまとめてDownloadsへ保存し、macOSのショートカットを起動します。ショートカットはZIPを検証・展開し、各ページを別々のCUPSジョブとしてmC-Label3へ送ります。WebアプリがCUPSやプリンターへ直接接続することはありません。

この設定は、直接印刷を利用するMacごとに1回必要です。Webアプリと、ショートカットへ貼り付けたスクリプトは自動では同期されません。以前に設定したMacも、この文書の手順で[最新版スクリプト](../scripts/mclabel3-print-example.sh)を貼り直し、「通知を表示」アクションを追加してください。

通常の操作方法はNotionの[LABEL PRINT 利用開始マニュアル](https://app.notion.com/p/3c271be76cc581dc8ce6f76c2261e247)を参照してください。

## 1. プリンターを準備する

1. Star公式の[mC-Label3 ドライバーインストール手順](https://star-m.jp/products/s_print/oml/mclabel3/manual/ja/settings/driverInstall.htm)に従い、macOS用CUPSドライバーをインストールします。
2. macOSへmC-Label3を追加します。AirPrintや汎用ドライバーではなく、StarのmC-Label3用ドライバーで登録してください。
3. 使用するロール紙をセットし、紙幅ガイドとメディア設定を用紙に合わせます。詳しくはStar公式の[用紙をセットする](https://star-m.jp/products/s_print/oml/mclabel3/manual/ja/basicOperations/installingPaper.htm)と[メディア設定](https://star-m.jp/products/s_print/oml/mclabel3/manual/ja/settings/mediaSettings.htm)を参照してください。
4. ブラウザのダウンロード先を`~/Downloads`にします。「ダウンロード前に各ファイルの保存場所を確認する」が有効な場合は、直接印刷時にDownloadsを選びます。

ターミナルを開き、次を確認します。

```sh
lpstat -e
```

名前に`MCL32`を含むプリンターがちょうど1台表示される必要があります。表示された名前を使い、次も実行します。

```sh
lpoptions -p "プリンター名" -l
```

出力に`Custom.WIDTHxHEIGHT`が含まれることを確認します。さらに`Halftoning`に`1Monochrome`、`PrintSpeed`に`2Low`があれば、最新版スクリプトが対応する画質設定を印刷ジョブごとに安全に指定できます。

## 2. ショートカットを作成する

1. macOSの「ショートカット」アプリを開き、新規ショートカットを作成します。
2. ショートカット名を正確に`mC-Label3 Print`とします。
3. 右上の詳細（`i`）を開き、`共有シートに表示`をオンにします。
4. 1個目のアクションとして「シェルスクリプトを実行」を追加し、次のように設定します。
   - シェル: `/bin/zsh`
   - 入力: `ショートカットの入力`
   - 入力の渡し方: `引数として`
   - 管理者として実行: オフ
5. [scripts/mclabel3-print-example.sh](../scripts/mclabel3-print-example.sh)の全文を、シェルスクリプト欄へ貼り付けます。
6. 2個目のアクションとして「通知を表示」を追加します。
7. 通知本文を、直前の「シェルスクリプトの結果」に設定します。macOSの版によって表示名が異なる場合は、直前アクションの出力を示すマジック変数を選びます。固定メッセージにはしません。
8. 「ショートカット」>「設定」>「詳細」で、`スクリプトの実行を許可`をオンにします。

「共有シートに表示」を先にオンにすると、シェルの入力欄で`ショートカットの入力`を選べます。入力欄が空だとJSONが渡らず、`ERROR:印刷ジョブが空です`になります。

## 3. 初回の権限を許可する

初回実行時は、内容を確認したうえで次を許可します。

- ブラウザから`mC-Label3 Print`ショートカットを開くこと
- ショートカットからDownloadsへアクセスすること
- ショートカットの通知
- ショートカットでスクリプトを実行すること

通知が表示されない場合は、「システム設定」>「通知」>「ショートカット」で通知が許可されているか、集中モードで抑止されていないか確認します。

Apple公式の説明も参照できます。

- [共有シートからショートカットを起動する](https://support.apple.com/ja-jp/guide/shortcuts-mac/apd163eb9f95/mac)
- [ほかのアプリからショートカットを起動したときの出力](https://support.apple.com/ja-jp/guide/shortcuts-mac/apda9578f70f/mac)
- [「通知を表示」アクション](https://support.apple.com/ja-jp/guide/shortcuts-mac/apd2175adcab/mac)
- [Macの通知設定](https://support.apple.com/ja-jp/guide/mac-help/mchl205da693/mac)

## 4. 配線と実印刷を確認する

1. ショートカット編集画面で、入力を渡さず手動実行します。
2. `ERROR:印刷ジョブが空です`と通知されれば、シェルの出力から通知までの配線は正常です。この空入力テストでは期待どおりのエラーです。
3. WebアプリでサンプルCSVまたは実データを読み込みます。
4. 用紙幅、バーコード列、印刷対象を確認し、合計1ページにします。
5. 「mC-Label3で印刷」を押します。
6. ZIPがDownloadsへ保存され、ブラウザが`mC-Label3 Print`を開くことを確認します。
7. `OK:1ページを個別の用紙サイズで受け付けました`と通知され、実際に1枚印刷されることを確認します。

`OK:`は全ジョブをCUPSが受け付けたという意味で、用紙への物理印刷完了を保証するものではありません。必要に応じて次のコマンドでキューを確認します。

```sh
lpstat -o "プリンター名"
lpstat -W completed -o
```

## ショートカットの処理

```text
Shortcut InputのJSONを検証
-> Downloads内の印刷ZIPを最大10秒待機
-> ZIPとmanifest.jsonを検証して展開
-> lpstat -eでmC-Label3を検出
-> lpoptionsでCustom PageSize対応と画質オプションを確認
-> 各1ページPDFを固有の幅・高さでlpへ順次送信
-> シェル結果のOK:またはERROR:をMac通知へ表示
```

Webアプリが作る`mclabel-{UUID}.zip`には、次のファイルが入ります。

- `manifest.json`: ページ順、PDF名、各ページの幅と高さ
- `mclabel-{UUID}-p000001-{width}x{height}mm.pdf`のような1ページPDF

コピー枚数も独立したページPDFになります。高さが同じページも異なるページも、1ページずつ印刷要求を送ります。

## CUPSへ送る設定

各ページは、検証済みの値を使って次と同等のコマンドで送られます。

```sh
lp \
  -d "$PRINTER" \
  -o "media=Custom.${WIDTH_MM}x${HEIGHT_MM}mm" \
  "${JOB_OPTIONS[@]}" \
  -- "$FILE"
```

`JOB_OPTIONS`には、登録中のドライバーが完全一致する選択肢を公開している場合だけ、次を個別に追加します。

- `Halftoning=1Monochrome`: バーコードと文字をモノクロ処理する
- `PrintSpeed=2Low`: 低速の高品質設定で印刷する

ドライバーが片方または両方を公開していない場合、そのオプションだけを省略して印刷を続けます。`PrintDensity`と汎用の`print-quality`は変更しません。濃度はプリンターキューの既定値を使用します。

`fit-to-page`、`lp -n`、自動拡大縮小は使用しません。直接印刷PDFはプリンターの203dpiドットへ合わせています。

たとえば画面で58mmを選ぶと、直接印刷データは464ドットになります。Starドライバーの203dpiと1ドット単位で一致させるため、CUPSのCustom幅やZIP内では約58.057mmと表示されます。これは再拡大縮小を防ぐための意図した補正で、画面の設定ミスではありません。

## エラー別の対処

| Macの通知 | 原因と対処 |
| --- | --- |
| `ERROR:印刷ジョブが空です` | `共有シートに表示`、シェルの入力=`ショートカットの入力`、渡し方=`引数として`を確認します。手動の空入力テストなら正常です。 |
| `ERROR:印刷ZIPが見つかりません` | ZIPがDownloadsへ保存されたか、ブラウザのダウンロード許可、ショートカットのDownloadsアクセス、ダウンロード完了を確認します。 |
| `ERROR:mC-Label3が見つかりません` | `lpstat -e`に`MCL32`を含むキューがありません。Star CUPSドライバーとプリンター登録を確認します。 |
| `ERROR:mC-Label3が複数存在します` | 古いキューや重複登録を整理します。誤送信を避けるため、1台に特定できない場合は停止します。 |
| `ERROR:プリンターオプションを取得できません` | `lpoptions -p "プリンター名" -l`を直接実行し、CUPS、キュー、ドライバーを確認します。 |
| `ERROR:Custom PageSize非対応です` | AirPrintや汎用ドライバーで登録されている可能性があります。StarのCUPSドライバーで登録し直し、`Custom.WIDTHxHEIGHT`を確認します。 |
| ZIP、manifest、UUID、ファイル名、寸法の不整合エラー | Webアプリを再読込し、最新版スクリプトを貼り直してジョブを作り直します。ZIPの中身を手作業で編集しないでください。 |
| `ERROR:Nページ目のlp印刷失敗: ...` | 失敗ページより前はCUPSへ送信済みの可能性があります。キューと完了ジョブを確認してから再実行し、重複印刷を避けます。通知末尾のエラーも記録します。 |
| Webアプリでは起動成功だが通知がない | 「通知を表示」アクション、通知本文のマジック変数、通知許可、集中モードを確認します。 |
| `Halftoning`や`PrintSpeed`が追加されない | エラーではありません。ドライバーが対応値を公開していないため安全に省略しています。Starのドライバーで登録されているか確認します。 |
| `OK:`だが紙が出ない | `OK:`はCUPS受付までです。用紙、カバー、接続、プリンターキューの一時停止・保留を確認します。 |

## 安全対策

- ZIP名、UUID、ページPDF名、ページ番号、幅、高さを固定形式で検証します。
- ZIP内には`manifest.json`と許可形式のPDF名以外を認めません。
- `/`、`\\`、`../`を含むZIP内パスを拒否してから展開します。
- 展開したファイルがシンボリックリンクの場合は印刷しません。
- 幅と高さは正の数値、小数3桁までに限定します。
- manifest、PDF名、Shortcut入力のジョブID・ページ数・寸法が一致することを確認します。
- `eval`は使用せず、変数を引用符で囲んでCUPSへ渡します。
- `MCL32`を含むプリンターが0台または複数台の場合は印刷しません。
- `Custom.WIDTHxHEIGHT`非対応の場合は印刷しません。

途中のページでエラーになった場合、それ以前のページはすでにCUPSへ送信済みで、失敗ページ以降は送信されません。
